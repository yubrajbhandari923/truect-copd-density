## Setup

Fit on 46 TRAIN subjects (300k voxels each from the shared evaluation region, seeded), scored on the 10 VAL
subjects with `truect.metrics` (region: inside phantom, not outside air, inside the reconstruction disc).
All baselines are 1-D lookups on (optionally Gaussian-smoothed) CT, frozen to `frozen_comparators.json` for E04.

## Results (median over 10 validation subjects; range)

| Baseline | density MAE g/cm3 | pure voxels | boundary voxels | bias | material macro Dice |
|---|---|---|---|---|---|
| B0 1 + HU/1000 (reference, CT only approx. HU) | 0.084 (0.074–0.101) | 0.074 | 0.149 | -0.021 | |
| B1 isotonic map on raw CT | 0.060 (0.048–0.074) | 0.050 | 0.146 | -0.027 | |
| B2 MLP on raw CT | 0.065 (0.057–0.079) | 0.056 | 0.134 | -0.034 | |
| B3 B1 on smoothed CT (sigma 1 voxel, val-selected) | **0.053 (0.037–0.065)** | 0.041 | 0.145 | -0.026 | |
| B4 per-bin majority material (sigma 1) | | | | | **0.345 (0.284–0.385)** |

- Boundary voxels carry ~3.5x the error of pure voxels: intensity alone cannot resolve partial volume.
- Emphysema density MAE 0.056 g/cm3 (B3), as large as emphysema density itself (0.023–0.083): not recoverable
  from CT intensity alone. Thin structures are worst: fissure 0.54, skin 0.29, vessel 0.27, ID-6 'lung' 0.18.
- B4 material Dice: lung 0.91, body fat 0.82, soft tissue 0.78, rib/scapula bone 0.52; blood, skin, spine and
  sternum bone 0 (indistinguishable by intensity from neighbours), internal air 0.13.
- B2 (MLP) is worse than B1: with one input it is just a smoother curve fitted with squared loss; kept as the
  plan's capacity control.
- Validation selection (sigma) used the same 10 subjects that are reported: slightly optimistic; E04 is unbiased.
